## 2026-08-22 英語版まわり（ゲートが効き始めた回）

  → CJK リークテスト＋`INTENTIONAL_JP` 許可リスト。ミューテーションにも登録。**消化済み**
- [rule] 英語版を日本語版の直訳として作っていた。「日本語で教わる」は英語話者には無価値。
  → 「Japanese＝基準」に統一し、テストで逆戻りを防止。未確認の英語対応は約束しない。**消化済み**
- [verify] ミューテーション #8 が最初**生き残った**。テストが「描画テキスト」しか見ておらず、
  辞書に眠る未使用エントリを見ていなかったため。self-test が無ければ気付けなかった
  → 走査対象を「描画＋属性＋i18n 辞書」に拡張。**self-test が実際に穴を発見した最初の事例**。**消化済み**
- [verify] ベースライン画像が 1px 差で落ちた（PADI 追加でページ高が変わり、リングのY端数が変化）。
  **通すためのベースライン更新は禁じ手**なので、撮影を整数座標＋固定サイズ clip にして決定論化し、
  3回連続一致を確認してから撮り直した。**消化済み**
- [waste] ブラウザのCSSキャッシュで「CSSが効いていない」と誤認し、ルールの有無を疑って往復した。
  → 計測時は `Network.setCacheDisabled` を先に入れる。**消化済み**
- [verify] **ミューテーション自体が腐った。** #7 は `"Small groups. Never a rushed one."` を
  狙っていたが、その直後に文言を `"Everything is run to a Japanese standard."` に変更したため、
  何も壊さないミューテーションに変質し「SURVIVED（未カバー）」と誤報告された。
  検証の欠陥ではなく検証の腐敗で、原因の切り分けを誤らせる。
  → 適用前後のハッシュ比較で **STALE と SURVIVED を区別**。両方向（一致しない置換／実際の置換）で
  検出ロジックを確認済み。POLICY.md §3b と `loop-init` にも一般則として追加。**消化済み**
- [rule] self-test は snapshot したファイルを最後に restore するため、**実行中に同じファイルを
  編集すると変更が消える**。バックグラウンド実行中は対象4ファイルを触らない運用にした（今回は回避済み）。
- [verify] **「決定論にした」が不十分だった。** clip 原点を整数にしただけでは、要素自身の
  小数位置によるアンチエイリアス差が残り、スケジュール短縮（＝上の要素の高さ変化）だけで
  ベースラインが落ちた。→ 撮影前に対象を `translate` で整数位置へスナップし、撮影後に戻す方式へ。
  **無関係な変更（sched の gap を意図的に広げる）を加えても通ることを確認**してから確定した。
  「安定させた」と言う前に、揺らす要因を実際に加えて試すこと。**消化済み**
